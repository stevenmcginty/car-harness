The jobs a forecourt actually needs after work on a car: reset the service counters, register a new battery, and ask the gateway what the car is really made of. These run BMW's own diagnostic jobs over the ENET cable — the car has to be awake, ignition on.

Simulation mode. Nothing below touches a real car — every value is made up and clearly marked.

Service intervals (CBS)

Condition Based Service is what the driver sees as "service due". It lives in the cluster, the engine and the ABS unit — each item is owned by one of them — and it is not the same record as the iDrive service history. A full service usually wants both: write the history entry here.

Battery

Condition comes from the engine's own power management and the sensor on the battery's negative terminal. Register a replacement only after a new battery has actually been fitted — it resets the charge history so the car charges a new battery properly and lets start/stop work again. It does not change the coded battery type or capacity; a different size, or AGM in place of lead-acid, needs coding this harness doesn't do.

What's actually fitted

The module scan probes a fixed list of addresses and calls silence "not fitted" — which can't tell a missing module from a sleeping one. The gateway holds the car's own list of control units, so this is the car's answer rather than ours.
