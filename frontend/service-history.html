Modern BMWs and MINIs have no paper service book. This builds the entry that appears in the car's own service history, so a car you serviced says so on the customer's screen. It writes text, not the car — the last step is a Tool32 job over the ENET cable, and the run sheet is at the bottom.

    Which .prg to load

    The job lives inside the head unit's own file. Load the wrong one and the job list simply won't have it. Run a module scan first — the head unit is address 0x63.

    Head unitFileReported

    At the car

    1. ENET cable in the OBD port, ignition on, battery support on if it'll be a while.
    2. Tool32 → Configuration → EDIABAS → interface ENET.
    3. File → Load SGBD and pick the .prg for this car's head unit.
    4. Select the job steuern_servicehistory_add.
    5. Paste the argument above, then run it — double-clicking the job runs it immediately, there's no confirmation.
    6. Run STEUERGERAETE_RESET (or cycle the ignition) or the entry won't show.
    7. Check it on the screen: Vehicle info → Service history.

    Entering an older service? Add them oldest first — they append in the order you write them.

    The other record — BMW's own

    This page writes the car. BMW also keeps a central Digital Service Book on its own servers — that's the one a main dealer sees, and the one that can overwrite what you put in the car. There is no route to it over any cable. It's a registered-workshop login: aos.bmwgroup.com, then the service goes in through KaSIO. Independent access is a right-to-repair entitlement, not a favour — you register the business and pay per ticket rather than joining a scheme.
